# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** and describe the issue, the affected
   version and how to reproduce it.

You'll get a reply within a few working days. Once a fix is released, the
advisory is published with credit to you, unless you'd rather stay anonymous.
